# College Projects

A collection of standalone C++ and Python projects focused on systems
programming, object-oriented design, real-time graphics, and interactive
simulation.

## Interactive Graphics

| Project | Focus | Stack |
| --- | --- | --- |
| [Polyhedral Atlas](<Interactive Graphics/Polyhedral Atlas/README.md>) | Platonic-solid geometry, topology, and duality | Python, Pygame, PyOpenGL |
| [Helios Orrery](<Interactive Graphics/Helios Orrery/README.md>) | Hierarchical orbital animation and camera tracking | Python, Pygame, PyOpenGL |
| [LightForge](<Interactive Graphics/LightForge/README.md>) | OBJ loading, generated normals, and GLSL shading | Python, Pygame, PyOpenGL, GLSL |
| [Crystal Dice Foundry](<Interactive Graphics/Crystal Dice Foundry/README.md>) | Textured polyhedra and quaternion-based dice motion | Python, Pygame, PyOpenGL |
| [Embervault](<Interactive Graphics/Embervault/README.md>) | Procedural first-person maze with lighting and audio | Python, Pygame, PyOpenGL |
| [Atomic Resonance](<Interactive Graphics/Atomic Resonance/README.md>) | Atomic structure and photon-emission visualization | Python, Pygame, PyOpenGL |
| [Aether Reactor](<Interactive Graphics/Aether Reactor/README.md>) | Multi-mode real-time particle simulation | Python, Pygame, PyOpenGL, GLSL |

## Additional Software

- [Key Management System](<A Key Management System>) — file-backed C++ key
  inventory and employee lookup system.
- [Tamagotchi Pet Game](<Tamagotchi Pet Game>) — object-oriented C++ virtual

Each directory is self-contained. Open a project's README for dependencies,
